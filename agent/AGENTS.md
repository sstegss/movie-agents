# Агенты системы

Система собрана в один граф LangGraph. Каждый агент отвечает за свою часть работы, решение о маршруте принимает Jev-like модель на входе.

| Агент | Модель | Что делает | Инструменты |
|---|---|---|---|
| gate (Jev-like) | свой классификатор, без LLM | определяет намерение, сложность и наличие вкусов, блокирует атаки | нет |
| memory | qwen3.5:2b (cheap) | достаёт из сообщения факты о вкусах и записывает их | поиск по каталогу делает код, не модель |
| recommender | qwen3.5:2b (cheap) или qwen3.5:4b (main) | подбирает фильмы | recommend_for_user, similar_movies, top_movies, search_movies |
| info | qwen3.5:2b (cheap) или qwen3.5:4b (main) | отвечает на вопросы о фильмах | search_movies, movie_details |
| chat | qwen3.5:0.8b (tiny) | приветствия, вопросы о самом ассистенте и о памяти | нет |
| validator | gemma4:e2b | проверяет ответ перед отправкой | проверки по каталогу в коде |

## Правила взаимодействия

1. Агенты не вызывают друг друга напрямую. Переходы задаёт граф, поэтому путь каждого запроса виден в трейсе.
2. Ответы recommender и info всегда проходят валидатор. Сначала идут детерминированные проверки по каталогу, потом проверка смысла моделью другого семейства.
3. Если валидатор отклонил ответ, агент получает замечания и одну попытку исправиться, уже на основной модели. Если и она не прошла, пользователь получает ответ, собранный прямо из результатов инструментов.
4. Агент памяти пишет только в профиль текущего пользователя. Чужие профили недоступны ни одному агенту.
5. Сообщения, которые gate пометил как unsafe или off_topic, до LLM не доходят.
