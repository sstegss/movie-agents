# Инструменты

Все инструменты работают с локальным каталогом MovieLens и рекомендательной системой из С1СЗ3. В сеть ни один из них не ходит.

| Инструмент | Зачем | Что возвращает |
|---|---|---|
| `search_movies(query, genre, year_from, year_to, limit)` | найти фильм по названию (английскому, допускает опечатки) или выбрать по жанру и годам | список «название [id; жанры]» |
| `movie_details(movie_id)` | год, жанры, средняя оценка, число оценок, популярные теги | JSON |
| `similar_movies(movie_id, k)` | фильмы, похожие на данный | список |
| `recommend_for_user(genre, year_from, year_to, k)` | персональные рекомендации по профилю пользователя из памяти | список |
| `top_movies(genre, year_from, year_to, k)` | лучшие по оценкам фильмы с фильтрами | список |

Правила:

- id фильма берётся только из ответа инструмента;
- если поиск ничего не нашёл, нужно попробовать английское название или сказать, что фильма нет;
- рекомендации без инструмента запрещены, валидатор такие отклоняет.
