# Сравнение LLM на задачах киноассистента

Железо: Intel i3-7100 (2 ядра), 16 ГБ RAM, без GPU (Radeon RX 580 не поддерживается ROCm). Ollama 0.40.7, модели из библиотеки Ollama.

Столбцы:

- **Инструмент**: доля из 5 запросов, где первым вызван подходящий инструмент;
- **Аргументы**: из них ещё и аргументы правильные (жанр, английское название);
- **JSON / Память F1**: агент памяти, 5 сообщений, F1 по фактам после сверки с каталогом;
- **Без выдумок**: из 6 вопросов «существует ли фильм» без инструментов, половина фильмов выдумана;
- **Судья**: из 4 пар верно ли поставлен pass/fail;
- скорость взята из счётчиков Ollama, RAM из `ollama ps` после загрузки. Для Gemma 4 это число меньше размера на диске: судя по всему, `ollama ps` учитывает не все веса (часть эмбеддингов по слоям), поэтому сравнивать RAM между семействами по этому столбцу не стоит.

Задач в каждой группе от 4 до 6, поэтому разница в одну задачу это 17–25 процентных пунктов. Таблица годится, чтобы отсеять явно неподходящие модели, а не чтобы различать близкие.
