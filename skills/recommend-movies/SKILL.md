# Как подбирать фильмы

1. Выпиши условия из запроса: жанр, годы, фильмы-образцы («как Интерстеллар»), что исключить. Жанр переведи в название из списка жанров MovieLens (ниже).
2. Выбери инструмент:
   - есть фильм-образец: найди его через `search_movies` по английскому названию, возьми id, вызови `similar_movies`;
   - образца нет: вызови `recommend_for_user` с фильтрами. Он сам учитывает профиль из памяти, а без профиля отдаёт лучшие по оценкам;
   - просят «лучшее/топ»: вызови `top_movies`.
3. Из результатов выбери 3–5 фильмов, которые подходят под все условия. Фильмы, которые человек уже видел или не любит, инструмент убирает сам.
4. Ответ: нумерованный список «Название (год): почему подходит» одной строкой на фильм. Название копируй из результата инструмента без изменений.

Нельзя:
- советовать фильм, которого не было в результатах инструментов;
- придумывать сюжет. Если хочешь объяснить выбор, опирайся на жанры и сходство с образцом.
